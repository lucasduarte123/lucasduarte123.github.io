auth.cy.jsexemplo ilustrativo
const tokens = {
  valido:   Cypress.env('TOKEN'),
  ausente:  null,
  invalido: 'abc.def.ghi',
  expirado: Cypress.env('TOKEN_EXP'),
};

Object.entries(tokens).forEach(([caso, t]) => {
  it(`query pedido — token ${caso}`, () => {
    cy.gql(QUERY_PEDIDO, { id: '123' }, t)
      .then(({ body }) => {
        if (caso === 'valido') {
          expect(body.errors).to.be.undefined;
          expect(body.data.pedido.id).to.eq('123');
        } else {
          expect(body.errors[0].extensions.code)
            .to.eq('UNAUTHENTICATED');
        }
      });
  });
});

Loja virtual de iluminação em Magento

Desafio
Produtos sem preço definido, que deveriam ser vendidos só sob consulta, apareciam na loja com botão de compra ativo e preço zerado. Qualquer cliente podia fechar um pedido de graça.
O que fiz
Identifiquei o padrão nos produtos afetados, reproduzi o fluxo até o checkout e criei um script que oculta o botão de compra sempre que o produto está marcado como sob consulta.
Resultado
Fim dos pedidos indevidos a R$ 0 e a regra ficou automática para todo produto novo cadastrado sem preço.
